## 1.2、为什么一定要用git

- 主流工作中使用svn、git两种工具进行代码管理，必须会其中一个，自学过程中比较好获取的是git，并且主流开发为git，并方便对面试官展示自己的成果
- 自己调试代码的过程中，避免改动导致自己的代码异常，使用git进行版本管理，即使代码修改烂掉了，也可以有稳定版本回溯

## 1.2、养成良好的代码、笔记管理习惯

- 面试的时候如果可以进行成果展示，可以展示git、笔记等内容，让面试官有直观的感受知道你的学习能力
- 完成自己的知识体系搭建

## 1.3、创建以下仓库

- 周报仓库（用于存放每周任务进展、临时调试小demo）
- 调试的SOC源码仓库，比如imx6ull的uboot、kernel、rootfs
- 笔记仓库（用于搭建自己的知识体系，比如git使用学习、交叉编译工具链搭建学习笔记）

# 2、笔记要求

## 2.1、个人知识笔记

- 记录有价值的问题，必要需要提交截图
- 禁止纯AI生成一套笔记，如果AI生成需要自己梳理一遍消化吸收
- 笔记中需要有自己的思考

- 遇到问题的解决笔记要有以下内容章节（根据实际情况删减）

    （1）问题现象

    （2）复现过程

    （3）问题分析

    （4）根因定位

    （5）解决措施（或者优化方案）

    （6）验证结果

# 3、git提交要求

- 要求自己以统一的message提交git
- 以下是参考，逐渐形成自己的提交风格，不同公司部门的提交要求不一样，提前培养规范意识

```shell
git commit -m "[ADD][NOTE]添加了xxxxxx"
git commit -m "[CHG][OBC_SDK]添加了xxxxxx"
git commit -m "[DEL][imx6ull sdk]添加了xxxxxx"
```
